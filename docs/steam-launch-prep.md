# Steam Launch-Prep Checklist

For when Space-Game is ready for a Steam page. You don't need this all today —
but **wishlists are the single biggest lever for a Steam launch**, so getting a
"Coming Soon" page up *before* launch (once you have decent art + a trailer) is
worth doing earlier than most people expect.

## Phase 0 — Account setup (your LLC)

- [ ] Create a **Steamworks** account as your LLC.
      Use the EIN and business details. Steam will require tax info (W-9 for a
      US LLC) and the **business bank account** for payouts — enter the same
      account tied to your EIN so all Steam revenue routes there.
- [ ] Pay the **$100 Steam Direct fee** per app (recoupable after $1,000 in
      sales).
- [ ] Complete **identity & tax verification** (can take a few days — don't
      leave it to the last minute).

## Phase 1 — Store assets you'll need

Steam requires specific image sizes. Line up:

- [ ] **Header capsule** — 460×215 (the main thumbnail; most important art you'll
      make).
- [ ] **Small capsule** — 231×87.
- [ ] **Main capsule** — 616×353.
- [ ] **Vertical capsule** — 374×448.
- [ ] **Page background** + **library assets** (hero 3840×1240, logo, etc.).
- [ ] **5+ screenshots** — 1920×1080, showing actual gameplay (co-op moments sell
      this game).
- [ ] **A trailer** — even 30–60s of real gameplay. This matters more than
      polish; show the *fun*.

## Phase 2 — Store page copy

- [ ] Short description (the blurb under the trailer) — lead with the hook:
      "1–4 friends, one ship, online or LAN."
- [ ] About / long description with GIFs.
- [ ] Tags (Co-op, Online Co-Op, LAN, First-Person, Space, Adventure…).
- [ ] System requirements.
- [ ] Genres & content rating questionnaire.

## Phase 3 — Wishlist engine (do this early)

- [ ] Publish the **"Coming Soon"** page as soon as it passes Steam review.
- [ ] Drive every channel to it — itch page, Discord, README, socials, trailer
      end-card. **Wishlists pre-launch directly feed Steam's launch-day
      visibility.**
- [ ] Plan a **Steam Next Fest** demo slot — a free demo during Next Fest is one
      of the best wishlist drivers available for an unknown indie.

## Phase 4 — Pre-launch

- [ ] Set price & regional pricing (Steam suggests regional values).
- [ ] Set up a **demo** build if possible (you already give builds on itch).
- [ ] Build a launch-day post for Discord + email list + socials.
- [ ] Consider a **Playtest** (Steam's built-in closed-playtest feature) to move
      your itch testers onto Steam early and seed reviews/wishlists.

## Rough timing

| When | Do |
| --- | --- |
| Now | Keep itch devlog active; grow Discord + email list |
| Vertical slice + basic art | Steam account, capsule art, **Coming Soon page** |
| Pre-launch (1–3 mo) | Trailer, Next Fest demo, wishlist push |
| Launch | Coordinated post across all channels |
