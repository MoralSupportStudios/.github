# Moral Support Studios

Indie game studio building co-op multiplayer titles in Unity 6.

## 🚀 In development

**[Space-Game](https://github.com/MoralSupportStudios/Space-Game)** — first-person, online + LAN, multi-floor interior-ship adventure where 1–4 friends crew a derelict ship between hostile planets. Vibe-coded prototype, active development.

Play the latest build on [itch.io](https://theschlote.itch.io/friend-slop).
