# Support

Need a hand? Here's the fastest way to reach the right place.

| I want to… | Go here |
| --- | --- |
| 🐛 Report a bug or share playtest feedback | [Playtest bug template](https://github.com/MoralSupportStudios/Space-Game/issues/new?template=playtest-bug.yml) |
| 💡 Suggest a feature | [Feature request template](https://github.com/MoralSupportStudios/Space-Game/issues/new?template=feature-request.yml) |
| 🗺️ See what's planned | [Project board](https://github.com/orgs/MoralSupportStudios/projects) |
| 🎮 Play the latest build | [moral-support-studios.itch.io/space-game](https://moral-support-studios.itch.io/space-game) |
| 🔒 Report a security issue | See [SECURITY.md](./SECURITY.md) |
| ✉️ Anything else | [Support@MoralSupportStudios.com](mailto:Support@MoralSupportStudios.com) |

A few tips for getting help faster:

- **Search existing issues first** — someone may have already hit the same thing.
- **Include your build version and platform** when reporting a bug.
- **One topic per issue** keeps conversations easy to follow.

We're a small team and we read everything. We've got your back.
